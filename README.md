Built a human image segmentation model using PyTorch as part of a Coursera Guided Project. The project involved data preprocessing, augmentation with Albumentations, custom dataset creation, model training using Dice Loss, and inference visualization in a GPU-enabled Google Colab environment.
Tasks performed:

Set up a GPU-enabled environment in Google Colab

Downloaded and worked with a real-world Human Segmentation Dataset

Performed data preprocessing and visualization using OpenCV and Matplotlib

Split the dataset into training and testing sets

Applied data augmentation techniques using Albumentations to improve model generalization

Built a custom PyTorch Dataset class for handling image-mask pairs

Loaded data efficiently using PyTorch DataLoaders

Implemented a deep learning segmentation model using segmentation_models.pytorch

Used Dice Loss as the evaluation metric for segmentation performance

Developed training and validation pipelines

Trained the model and tracked performance across epochs

Performed inference and visualized predicted segmentation masks

**
Python

PyTorch

segmentation-models-pytorch (SMP)

Albumentations (for data augmentation)

OpenCV
